# 📖 About This Repository

Welcome to my official UI/UX internship portfolio repository!  
This repository contains all the design files, prototypes, wireframes, and case studies created during my UI/UX journey.

The main objective of these projects was to improve my design thinking process — from low-fidelity wireframing and user research to building polished high-fidelity interfaces and interactive prototypes using modern design principles.

📸 **Media Included:**  
Along with Figma links, this repository also includes screenshots, design previews, and interactive prototype demonstrations for each task.
